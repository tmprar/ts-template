# レビューの観点: 正しさと安全性

コードの呼び出し元とデータの流れを読んで、誤った結果や情報の漏れが無いかを確かめる観点。`find` の担当 `correctness` に渡す。

## 正しさと安全性(コードを変えた PR)

規約に書かれておらず、機械でも検査できないもの。

- 変更したコードが、意図した入力と状態に対して誤った結果を返さない。規約に関わらない不具合もこの観点で指摘する
- 境界値、日時とタイムゾーンの扱い、同じ資源への同時の更新、ジョブの再実行で、誤った結果にならない
- 利用者のデータを返す・変えるルートが、その利用者が読み書きしてよいデータだけを対象にしている
- トークンや個人情報を、ログ・エラー応答・メールに出していない
