## 4. 機能要件

各要件の実装状況は各表の「状況」列を正とする(実装したら該当 ID をここで更新する)。

### 4.1 todo(サンプル)

| ID | 要件 | 状況 |
|---|---|---|
| TODO-1 | todo を追加できる。件名は前後の空白を除いて 1〜100 文字 | ✅ 実装済み |
| TODO-2 | todo を追加した順に一覧できる | ✅ 実装済み |
| TODO-3 | todo を完了にできる。すでに完了している todo は完了にできない | ✅ 実装済み |
| TODO-4 | todo を削除できる | ✅ 実装済み |
| TODO-5 | todo が完了になったら、設定した宛先へメールで知らせる。送信は非同期に行い、送れなくても完了は成立する。失敗したら再試行する | ✅ 実装済み |
